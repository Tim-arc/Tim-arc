# Product

## Register

brand

## Users
Recruiters, hiring managers, technical leads, and developers evaluating Timofey Kosykhin's experience, projects, and engineering focus.

## Product Purpose
Present a clear, memorable GitHub profile that quickly communicates professional level, current role, completed education, core stack, and strongest projects.

## Brand Personality
Bright, technical, confident.

## Anti-references
Avoid an overloaded badge wall, decorative effects that obscure the content, generic résumé language, and a playful style that weakens professional credibility.

## Design Principles
- Put professional identity and current role first.
- Make important facts scannable in under a minute.
- Use vivid color as a signature, not as visual noise.
- Support claims with concrete stack details and project work.
- Keep Russian and English versions structurally consistent.

## Accessibility & Inclusion
Use readable contrast, descriptive image alt text, meaningful link labels, restrained animation, and a clear heading hierarchy compatible with GitHub Markdown.
